# Portfólio Profissional — Larissa Maria 📊✨

> **Portfólio moderno, responsivo e chamativo** desenvolvido sob padrões sênior de engenharia front-end para destacar competências em **Análise de Dados, Python, SQL, Power BI e Desenvolvimento de Software**.

---

## 🌟 Principais Destaques

- **Paleta Marcante & Contemporânea ("Cyber Orchid & Electric Cyan"):** Gradientes em fúcsia/magenta neon combinados com ciano tecnológico e fundo dark slate imersivo.
- **Alternador de Tema (Dark / Light):** Suporte nativo a modo escuro e claro com persistência em `localStorage`.
- **Vitrine Interativa de Projetos:** Sistema dinâmico de filtros (**Todos**, **Análise de Dados & BI**, **Python & Backend**, **Aplicações Web & SaaS**) integrado aos repositórios reais do GitHub da Larissa.
- **Conversão de Oportunidades & Recrutadores:**
  - Botão de WhatsApp direto com mensagem pré-configurada.
  - Cópia rápida de e-mail com 1 clique e notificação visual Toast.
  - Links diretos para LinkedIn e GitHub.
  - Formulário com redirecionamento de mensagem.
- **Narrativa & Soft Skills:** Integração da experiência comercial anterior com atenção aos detalhes, raciocínio quantitativo e resolução de problemas em dados.
- **Zero Bloat & Alto Desempenho:** Construído com HTML5 semântico, CSS puro e JavaScript moderno, sem dependências pesadas, garantindo carregamento instantâneo.

## 🚀 Como Visualizar Localmente

Basta abrir o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox, Safari) ou iniciar um servidor local com Python:

```bash
# Na pasta portfolio:
python -m http.server 8000
```
Depois, abra `http://localhost:8000` no seu navegador.

## 🌐 Como Publicar Online (Grátis)

### Opção 1: GitHub Pages (Recomendado)
1. No seu repositório GitHub, crie uma branch ou pasta com os arquivos do portfólio.
2. Acesse **Settings** > **Pages**.
3. Em **Source**, selecione a branch `main` e a pasta correspondente.
4. Seu portfólio estará online em `https://larissa-gif-has.github.io/portfolio/`.

### Opção 2: Vercel / Netlify
1. Arraste a pasta `portfolio/` para o dashboard da [Vercel](https://vercel.com) ou [Netlify](https://www.netlify.com).
2. O deploy será instantâneo com certificado SSL gratuito.
